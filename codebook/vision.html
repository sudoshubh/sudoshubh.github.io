Foundation

What Is Computer Vision?

Computer vision enables computers to extract meaning from images and videos.

Simple Definition

Computer vision is the field of artificial intelligence that develops methods for machines to interpret visual information.

It deals with questions such as:

  • What objects are present?
  • Where are they located?
  • What are they doing?
  • How are they related?
  • What does the complete scene mean?

Levels of Understanding

  1. Classification: one label for the whole image.
  2. Detection: objects plus approximate locations.
  3. Segmentation: one class label for every pixel.
  4. Recognition: identify a particular object or person.
  5. Scene understanding: understand context and relationships.
Why are multiple stages useful? A two-dimensional image is incomplete and ambiguous. The same object can look different because of lighting, scale, viewpoint, occlusion, background, and pose. Intermediate features such as edges, texture, depth, and shape help the system form a reliable interpretation.
Part 1

Image Processing

Image processing changes or analyzes pixel values before semantic understanding begins.

Image

An image is a two-dimensional discrete signal. Each pixel stores numerical information such as intensity or color.

Video

A video is a sequence of images called frames. Time provides an additional source of information.

Pixel

A pixel is a small sample of the visual scene. In an 8-bit grayscale image, values range from 0 to 255.

Color Models

Model Meaning Typical Use Important Point
RGB Red, green, and blue light channels. Monitors, cameras, televisions, digital images. Additive model: adding light produces white.
CMYK Cyan, magenta, yellow, and black ink. Printing. Subtractive model: ink absorbs light.
HSL Hue, saturation, and lightness. Image editing and color filtering. Separates color type, intensity, and brightness.
YCbCr Luminance and chrominance components. Image and video compression. Brightness can be handled separately from color.
HSL memory trick: Hue tells you which color it is. Saturation tells you how pure or intense it is. Lightness tells you how light or dark it appears.

  1. Color transform: convert RGB into brightness and color components.
  2. Downsampling: reduce color resolution because humans are more sensitive to brightness.

  5. Encoding: compress the remaining data, for example with Huffman coding.

Brightness, Contrast, and Dynamic Range

Brightness

Brightness is the average intensity of all pixels in a grayscale image.

B(I) = (1 / WH) Σᵥ Σᵤ I(u, v)

Contrast

Contrast describes how widely the intensity values vary around their average.

Contrast ≈ variation / average luminance

Dynamic Range

Dynamic range is the number of distinct intensity levels used by an image.

  • High dynamic range: many shades.
  • Low dynamic range: fewer shades and a flatter appearance.

Histogram

A histogram counts how frequently each intensity value occurs. It provides statistical information but does not tell where pixels are located.

Histogram interpretation: A narrow central peak usually indicates low contrast. A broad spread generally indicates stronger contrast. Peaks near the ends may indicate strong contrast but possible loss of detail.

Image Enhancement Methods

Technique Purpose Core Idea
Negative Invert intensities. g(x,y) = L - f(x,y)
Histogram Equalization Improve contrast. Spread crowded intensity values over a wider range.
Log Transform Compress large dynamic ranges. s = c log(1 + |r|)
Gray-Level Slicing Highlight a selected intensity range. Keep values in [A, B] bright and suppress others.

Noise and Spatial Filtering

Noise Type Description Useful Filter or Strategy
Gaussian / White Many small random intensity changes. Gaussian or averaging filter.
Impulse / Salt-and-Pepper A few pixels jump to extreme values such as 0 or 255. Median filter.
Speckle Granular multiplicative variation. Adaptive or median-type filtering.
Shot / Poisson Photon-counting variation, common in low-light images. Denoising or variance stabilization.
Spatial filtering: A small kernel is applied to a local image neighborhood. Low-pass filters smooth images, median filters remove impulse noise, and sharpening filters emphasize edges and fine details.
Part 2

Video Processing

Video processing uses temporal information: how visual content changes from one frame to the next.

Video Compression

I-Frame

A self-contained keyframe. It can be decoded without other frames.

P-Frame

A predicted frame that uses information from a previous frame.

B-Frame

A bidirectionally predicted frame that uses both past and future frames.

Why not use only B-frames? B-frames require future frames for decoding. This increases delay, memory requirements, and complexity, which is undesirable in real-time applications such as video calls.

Optical Flow

Optical flow estimates the apparent motion of pixels or visual points between consecutive frames. Each flow vector has a horizontal component, a vertical component, a direction, and a magnitude.

flow magnitude = √(u² + v²)
Type What It Estimates Advantage
Sparse Flow Motion at selected informative points. Efficient and useful for tracking features.
Dense Flow Motion for almost every pixel. Provides a detailed motion field.

Video Descriptors

HOG

Histogram of Oriented Gradients. Describes appearance, shape, edges, and spatial structure.

Question answered: What does the object look like?

HOF

Histogram of Optical Flow. Counts motion vectors according to their directions.

Question answered: Which way is the object moving?

MBH

Motion Boundary Histogram. Uses gradients of optical flow to describe where motion changes.

Question answered: Where does motion differ from the background?

Memory sentence: HOG describes appearance and shape. HOF describes motion direction. MBH describes motion boundaries.

Modern Video Understanding

Person Search

Given one portrait image, find the person throughout a video even when pose, clothing, and lighting change.

Efficient Object Detection

Modern systems share object detections over time using motion and scene consistency rather than treating every frame as completely independent.

Video Interpolation

Generate intermediate frames between existing frames to create smoother or higher-frame-rate video.

Video Understanding

Move beyond object and action detection toward characters, relationships, events, storylines, and summaries.

Part 3

Semantic Segmentation Foundations

Semantic segmentation assigns a class label to every pixel in an image.

One-line definition: Semantic segmentation = dense pixel-wise classification.
Image
→
Features
→

Pixel Mask

Classification vs Detection vs Segmentation

Task Output Question Answered Example
Classification One label for the image. What is in the image? Street scene.
Object Detection Class, bounding box, and confidence score. Where is the object approximately? Car here, person there.
Semantic Segmentation One class label for each pixel. Which class does each pixel belong to? Road, car, sky, person.
Instance Segmentation Separate mask for each object instance. Which individual object is it? Car 1, car 2, car 3.
Panoptic Segmentation Class and instance information together. What is every region and which object instance is it? Road plus person 1, person 2, and car 1.

Formal Representation

For an RGB input image of height H and width W:

I ∈ R^(H × W × 3) Y ∈ {1, ..., C}^(H × W)

Before choosing the final class, the network conceptually produces one score for every class at every pixel:

Network output = H × W × C logits ŷ(x,y) = argmax₍c₎ P(c | x,y)
Example: If an image has dimensions 256 × 256 and five classes, the output before argmax is 256 × 256 × 5. The final mask is 256 × 256.

Why Classification CNNs Are Not Enough

Classification CNN

  • Compresses spatial information.
  • Uses pooling and global aggregation.
  • Produces one vector or one image-level label.
  • Exact object boundaries become less important.

Segmentation Network

  • Must preserve a spatial grid.
  • Must predict a class at every location.
  • Must preserve small structures and boundaries.
  • Needs both semantic context and spatial precision.

What Improves?

  • Larger receptive field.
  • More semantic abstraction.
  • Better understanding of objects and context.

What Is Lost?

  • Fine boundaries.
  • Thin structures.
  • Small objects.
  • Exact spatial position.
Important: Deep layers know more about WHAT is present, but less precisely WHERE it is.

Upsampling

Upsampling increases the spatial resolution of a feature map or prediction map. Common methods include nearest-neighbour interpolation, bilinear interpolation, and learned or transposed convolution.

Method How It Works Strength Limitation
Nearest-Neighbour Copies the closest value. Fast and preserves original values. Can create blocky boundaries and cannot recover lost detail.
Bilinear Uses weighted averaging of nearby values. Smoother output. Can blur boundaries and does not add semantic understanding.
Transposed Convolution Learns filters for increasing resolution. More flexible reconstruction. Cannot reconstruct information that was completely discarded.
Architecture Journey

From FCN to U-Net and DeepLab

Every architecture addresses a specific segmentation problem. Focus on the problem solved rather than memorizing names.

Architecture Main Idea Problem Addressed
FCN Keep a spatial feature grid and produce class-score maps. Converts a classifier into a dense predictor.
Encoder-Decoder Compress the image, then reconstruct a full-resolution mask. Recovers output resolution.
U-Net Combines encoder and decoder features through skip connections. Improves boundary and small-object recovery.
Dilated Convolution Enlarges receptive field without pooling. Adds context while preserving resolution.
ASPP Uses parallel dilation rates. Captures multiple context scales.
DeepLabv3+ Combines ASPP context with a boundary-refining decoder. Handles context and spatial precision together.

Skip Connections and U-Net

What Skip Connections Carry

  • Edges and local texture.
  • Precise object boundary information.
  • Fine spatial layout.
  • Early visual patterns lost after pooling.

Why U-Net Works

  • Deep features provide semantic meaning.
  • Early features provide spatial precision.
  • Matching encoder-decoder resolutions can be combined.
  • It works well when boundaries matter.
Core memory: U-Net = encoder-decoder with matching skip connections. Deep layers tell the model that a region is probably a car; skip features help determine exactly where the car boundary lies.

Dilated Convolution and ASPP

Dilated convolution inserts spaces between kernel samples. It sees a wider region while keeping the feature map resolution more stable.

Rate 1

Local view. Useful for fine detail.

Rate 2 or 6

Medium view. Adds object-level context.

Rate 12 or 18

Wide view. Adds scene-level context.

ASPP: Atrous Spatial Pyramid Pooling uses several parallel branches with different dilation rates, then concatenates their outputs. It is like asking several observers with different zoom levels to describe the same feature map.

Failure to Architecture Fix

Observed Failure Likely Architectural Fix
Blurry object boundaries Skip connections or a high-resolution decoder.
Small objects are missed High-resolution features or multi-scale design.
Road and sidewalk are confused Broader context or DeepLab-style context modules.
Thin structures disappear Reduce aggressive downsampling and add skip connections.
Object size varies significantly ASPP, feature pyramids, or multi-scale context.

A segmentation mask is commonly stored as a matrix of class IDs. For example:

0 = sky
1 = building
2 = road
3 = car
4 = person
Ignore labels: Some pixels are ambiguous, unlabeled, outside the annotation region, or difficult to classify at boundaries. An ignore label such as 255 excludes those pixels from loss computation.

Cross-Entropy Loss

Pixel-wise cross-entropy treats segmentation as classification repeated across the image grid.

CE = −log(P(true class))
Prediction for True Class Loss Interpretation
0.90 Approximately 0.105 Good and confident prediction.
0.50 Approximately 0.693 Uncertain prediction.
0.05 Approximately 2.996 Bad prediction with a large penalty.
L = (1 / |Ω|) Σᵢ CE(yᵢ, pᵢ)

Here, Ω is the set of valid pixels. Ignored pixels are excluded.

Handling Class Imbalance

Large regions such as road, sky, and background may dominate the training loss. Small but important classes such as pedestrians, tumors, or lane markings may be ignored.

Weighted Cross-Entropy

Assign larger weights to rare or safety-critical classes.

L = wᵧ · CE(y, p)

Caution: weights that are too large can make optimization unstable or increase false positives.

Focal Loss

Reduces the contribution of easy pixels and focuses learning on difficult or uncertain pixels.

Useful when easy background pixels dominate training.

Dice Loss

Useful when the foreground is small because it focuses directly on region overlap.

Data Augmentation Rules

  • Apply the same flip, crop, rotation, and scale to the image and mask.
  • Color jitter and image noise may be applied to the image only.
  • Do not interpolate class IDs as if they were continuous colors.
  • Use nearest-neighbour interpolation when resizing masks.
Common dataset bug: Bilinear interpolation can turn class IDs such as road = 1 and car = 2 into invalid values such as 1.5. Use nearest-neighbour interpolation for masks.

Typical Training Pipeline

  1. Load an image and its mask.
  2. Apply aligned augmentations.
  3. Run a forward pass to produce logits.
  4. Compute loss over valid pixels.
  5. Backpropagate and update parameters.
  6. Validate using metrics such as mIoU and Dice.
Evaluation

Metrics and Model Evaluation

A high pixel accuracy does not necessarily mean a useful segmentation model.

Pixel Accuracy

Pixel accuracy is the fraction of correctly classified pixels. It can be misleading when one class occupies most of the image.

Example: If a medical image contains 9,000 background pixels and 1,000 tumor pixels, a model that predicts background everywhere achieves 90% accuracy but has tumor Dice and IoU equal to 0.

IoU: Intersection over Union

IoU measures the overlap between a predicted region and the ground truth region.

IoU = |Prediction ∩ Ground Truth| / |Prediction ∪ Ground Truth|

IoU ranges from 0 to 1. Higher values indicate better overlap.

Dice Score

Dice = 2|P ∩ G| / (|P| + |G|)

Suppose the ground truth has 100 pixels, the prediction has 120 pixels, and the overlap is 80 pixels:

Dice = 2 × 80 / (120 + 100) = 0.727
IoU = 80 / (100 + 120 − 80) = 0.571
Do not confuse Dice and IoU. They both measure overlap, but their values are not directly interchangeable.

Mean IoU

Mean IoU computes IoU separately for each class and then averages the class scores.

mIoU = (IoU₁ + IoU₂ + ... + IoU꜀) / C

Example: road = 0.91, sky = 0.88, building = 0.75, car = 0.62, person = 0.40.

mIoU = (0.91 + 0.88 + 0.75 + 0.62 + 0.40) / 5 = 0.712

Metric Comparison

Metric Measures Strength Weakness
Pixel Accuracy Correct pixels overall. Simple to understand. Can hide poor rare-class performance.
IoU Overlap between prediction and target. Standard segmentation metric. May not fully capture boundary quality.
mIoU Average IoU across classes. Prevents dominant classes from hiding rare classes. Can hide variation unless per-class scores are inspected.
Dice Overlap with stronger emphasis on agreement. Useful for small regions and medical segmentation. Not numerically equal to IoU.
Boundary Quality Accuracy of object edges. Important for lanes, vessels, tumors, and surgical planning. Requires boundary-aware evaluation.
Debugging

Failure Analysis

Do not report only one metric. Inspect the predicted masks and identify the type of error.

Boundary Leak

The predicted mask spills outside the actual object or produces a blurry edge.

Possible causes: aggressive downsampling, weak decoder, low resolution, poor annotations.

Small Object Missed

Tiny classes such as pedestrians, lane markings, vessels, or small tumors disappear.

Possible causes: object shrinks to very few feature-map cells.

Class Confusion

Similar classes such as road and sidewalk receive incorrect labels.

Possible causes: similar texture, weak global context, ambiguous labels.

Occlusion

Partially visible objects receive incomplete masks.

Domain Shift

Performance drops when testing conditions differ from training: rain, night, a new camera, a new hospital, or a new satellite sensor.

Over-Smoothing

The model removes fine details and produces overly simple masks.

Debugging Checklist

  • Are image and mask transformations aligned?
  • Are mask class IDs correct?
  • Was nearest-neighbour interpolation used for masks?
  • Are ignored pixels handled correctly?
  • Is class imbalance severe?
  • Does validation contain diverse scenes and conditions?
  • Which class has the lowest IoU?
  • Are errors mostly boundary, scale, context, or domain-shift errors?
  • Have qualitative masks been inspected?
Engineering principle: When a mask is poor, ask whether the problem comes from data, preprocessing, loss, metric, architecture, or application constraints.
Modern Directions

Transformers and Foundation Segmentation

Modern methods connect dense masks with global context, prompts, and language.

Transformers

Attention allows distant regions of an image to influence one another. This helps when local texture is ambiguous.

For example, a gray region may be road, wall, roof, or shadow. Global scene context helps disambiguate it.

SegFormer

Uses a hierarchical transformer encoder to produce multi-scale features and a lightweight decoder for dense prediction.

Mask Classification

Instead of assigning a class independently at every pixel, the model predicts a set of mask and class pairs.

Examples include MaskFormer and Mask2Former.

SAM

Promptable segmentation produces masks from user prompts such as points, boxes, masks, or text-like cues.

Open-Vocabulary Segmentation

Uses language to specify the target, such as “segment the red car” or “find tumor-like regions.”

Model Selection

The best model depends on accuracy, latency, memory, annotation cost, robustness, and application risk.

Final conceptual shift: Segmentation is no longer limited to assigning one of a fixed set of class labels. It can become interactive, promptable, and language-conditioned.
